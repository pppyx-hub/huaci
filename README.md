# 划词翻译助手 · Huaci

选中文字即弹出释义，自动沉淀成可复习的生词本，再导出到 Obsidian。

Windows 桌面版，本地运行，数据全在自己电脑上。

---

## 它解决的问题

背单词软件的问题是：**你背的词，未必是你真正遇到的词**。

这个工具反过来 —— 你在读论文、看文档、刷网页时遇到不认识的词，
选中它，释义就出来了；点一下星标，它进你的生词本；
之后可以在词库里复习、做练习题、听发音，最后同步到 Obsidian 当笔记。

**词库是你自己的**，不是 App 推给你的。

---

## 功能

### 划词即译

- 在任何程序里选中文字，松开鼠标就弹释义
- 单词给音标、多词性释义、同义词、词形变化、例句
- 长句/段落给整句翻译 + 结构拆解
- 弹窗里可一键加入生词本、AI 解读、TTS 发音

### 词库管理

- 11 个维度筛选：我的生词 / 自动记录 / 待复习 / 雅思 / 学术 / 常用 / 生僻 / 顽固生词 / 手动录入 / 有同义词
- 难度分级：词频 + 柯林斯星级 + 考试标签加权，25 词人工样本命中率 80%
- 每个词可写**自己的批注**（和 AI 笔记分开存，互不覆盖）

### 练习中心

| 模式 | 说明 |
|---|---|
| 雅思挑战 | 从 1952 个常用雅思词里抽，不认识直接进生词本 |
| 英 → 中 / 中 → 英 | 选择题，答完显示每个选项的释义 |
| 同义词辨析 | 124 组人工整理的雅思同义替换，选项同词性同长度 |
| 造句练习 | 抽 3 个词自己写，对照 AI 参考写法 |

答题记录有统计：正确率、分模式明细、错得最多的词。

### 其他

- **发音**：有道真人发音，自动缓存，听过的词断网也能听
- **AI 笔记**：后台给标星词生成「场景 + 搭配 + 例句」，搭配经过自校验
- **问 AI**：针对某个词提问，比如「和哪个词最容易混」
- **Obsidian 同步**：词库变动自动写进 vault，无需手动操作

## 安装

### 方式一：下载 release

1. 下载 `划词翻译助手.zip` 解压
2. 双击 `划词翻译助手.exe`
3. 首次运行会在同目录建 `data/` 存词库

绿色版，拷走整个文件夹就能搬到别的电脑。

### 方式二：从源码跑

```bash
pip install flask pyinstaller pyside6 pillow
python huaci.py
```

词典文件需要单独准备（见下方「词典数据」）。

## 快捷键

| 快捷键 | 作用 |
|---|---|
| 选中文字 | 自动弹翻译 |
| `Ctrl + Alt + D` | 手动翻译剪贴板内容 |
| `Ctrl + Alt + L` | 打开词库 |
| `Ctrl + Alt + Q` | 暂停 / 恢复自动划词 |
| `Ctrl + Alt + E` | 退出 |

屏幕边缘的「译」悬浮球：单击开词库，拖动换位置，右键有菜单。

## 词典数据

同目录需要两个文件（release 版已内置）：

- `ecdict.db` — 从 [ECDICT](https://github.com/skywind3000/ECDICT)（MIT）导入的 SQLite，77 万词条，含词频、柯林斯星级、考试标签、词形变化
- `lemma.en.txt` — ECDICT 附带的词形还原表

生成方式：

```bash
python fetch.py          # 多线程分段下载 ecdict.csv（63MB）
python -c "import ecdict; ecdict.build()"   # 导入 SQLite
```

## AI 功能（可选）

AI 功能依赖本地 `llama-server` + 一个 gguf 模型：

```
ai_engine/
├── llama-server.exe
├── *.dll
└── qwen2.5-1.5b-q4.gguf
```

把 `ai_engine` 目录放到 exe 旁边即可启用。**没有它程序照常工作** ——
AI 笔记、问 AI、造句参考会自动隐藏，其余功能不受影响。

用 1.5B 模型是刻意的：这些功能不需要更强模型，而本地小模型零成本、零延迟、
不出网。实测它做「造句」和「判断搭配是否地道」很准，但**不能让它拆词根**
（会把 sustainable 说成 su+n+able）。

## 技术栈

- **界面**：tkinter（划词弹窗）+ Qt WebEngine（词库，HTML/CSS/JS）
- **后端**：Flask 本地 HTTP 服务，前端 fetch 调用（比 QWebChannel 稳）
- **数据**：SQLite（词库 + 词典 + 答题记录）
- **打包**：PyInstaller

为什么划词弹窗用 tkinter 而词库用 Web：划词要求毫秒级弹出，
WebEngine 初始化要 2 秒，不适合。词库是低频重交互，值得为排版质量付这个成本。
